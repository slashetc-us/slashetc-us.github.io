<p><em>Forget all of those magical command-line PDF incantations and edit<br />
your PDFs easily with Xournal.</em></p>
<p>
Somehow, despite all the issues with proprietary clients and the history of<br />
security issues with Acrobat, PDFs have become the de facto standard for your<br />
average print-ready document shared around the office. Sure, people might use<br />
some kind of open document format or a cloud editor if they intend to edit a<br />
document, but if the goal is to print the document or lock its<br />
contents in place, most people these days will export it to a PDF.</p>
<p>
Reading PDFs is typically fine on Linux, because Linux has plenty of<br />
applications that can open PDFs for viewing, and you easily can print PDFs<br />
under Linux as well. Even Adobe supplied a proprietary (and somewhat outdated)<br />
port of its Acrobat Reader for Linux. Some distributions also offer the<br />
ability to create a special software printer that converts any print job sent<br />
to it into a local PDF file.</p>
<p>
The problem comes when people want to turn read-only print-ready PDFs into<br />
read-write documents you need to modify. As more people work in paperless<br />
offices with strictly digital documents and fewer people own fax machines, you<br />
are more likely to find official documents like contracts show up in your<br />
INBOX in PDF format. These contracts likely were created with a proprietary PDF<br />
editor tool, and they usually have blanks for you to fill in and often<br />
signature lines so you can add a real signature. Unfortunately, for the longest<br />
time, even if you were using Adobe's own Linux port of Acrobat Reader, you<br />
couldn't reliably edit these PDFs, and you certainly couldn't easily add a real<br />
signature.</p>
<p>
A lot of Linux applications claim the ability to edit PDFs from<br />
graphical tools like GIMP, or the aforementioned Acrobat Reader or tools like<br />
Inkscape. In the past, I've even gone so far as to use command-line tools<br />
to convert a PDF into multiple pages of a different format, edit that<br />
format, then use the command-line tools to convert it back to a PDF.</p>
<p>
Then I discovered Xournal. Xournal is a graphical tool that's designed for<br />
note-taking and sketching either with a keyboard and mouse or even with a<br />
tablet and stylus. This program is pretty common, and you should be able to<br />
install it in any major Linux distribution, but otherwise, you can download the<br />
software from its <a href="http://xournal.sourceforge.net" rel="noopener noreferrer" target="_blank">Sourceforge<br />
page</a>.</p>
