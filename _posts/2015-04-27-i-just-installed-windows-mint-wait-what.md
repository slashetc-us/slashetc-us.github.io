<p>My Sunday afternoon was spent installing Windows... wait... Linux... oh I don't know at this point. It's stable as hell but looks like most peoples desktop. I'll call this mashup: Windows Mint. OK, you caught me. I did not install windows at all. Instead I wanted to see how close I could get Linux Mint to look like Windows, and I think I did a pretty damn good job. I started with Linux Mint 17.1 Cinnamon as a base install and went from there. This shows is the massive&nbsp;customizability of the Linux Operating System, with little effort.</p>

<p>Hardware:<br>
For the hardware I took my old Dell Optiplex 745 (tricked out of course) and installed basic Linux Mint Cinnamon. This rig is a Dual Core Intel Core 2 Duo @ 1.86Ghz, 4gb RAM (max I believe) and 320gb HDD. This guy also rocks an Nvidia 440GT and dual Dell 17in 1280x1024 displays.</p>
